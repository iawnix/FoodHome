# FoodHome Glossary

| Term | Meaning |
| --- | --- |
| Household | A private home space shared by members. |
| Member | A person inside one household. |
| Requester | The member asking for a dish. |
| Cook | The member preparing the meal. |
| Dish | A family menu item. |
| Order | One dish request for a meal. |
| Preference | Taste preference or exclusion used when ordering. |
| Reaction | Lightweight feedback during or after cooking. |
| Journal | A saved cooked-meal memory, planned after V0.1. |
